Data handling

What's sent: Only the clause text you select or paste, plus an anonymous device ID for rate limiting.
What's stored server-side: A daily request counter per device ID (reset at midnight UTC). No clause text, no IP, no personal data.
Retention: Counter expires after 2 days. OpenRouter (model provider) receives the text for classification only — see their privacy policy.
Local storage: Your device ID and pending selection stay in chrome.storage.local on this device only.
