§ ClauseRadar

Select a clause on any page, right-click, and choose Classify regulatory impact. Or paste text directly below.

Paste the old and new clause text to get a structured, significance-rated comparison.

ClauseRadar calls a hosted backend, no personal API key required. You get a limited number of free classifications per day.

Today's usage –
Data handling

What's sent: Only the clause text you select or paste, plus an anonymous device ID for rate limiting.
What's stored server-side: A daily request counter per device ID (reset at midnight UTC). No clause text, no IP, no personal data.
Retention: Counter expires after 2 days. OpenRouter (model provider) receives the text for classification only — see their privacy policy.
Local storage: Your backend URL, device ID, and pending selection stay in chrome.storage.local on this device only.
